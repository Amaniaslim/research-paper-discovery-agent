01 · Problem and solution

Literature search is fragmented.
This agent connects the trail.

Researchers move between search portals, PDFs, notes, and generic chat tools. The Research Paper Discovery Agent keeps discovery and evidence inspection in one traceable workflow.

Challenge

Too many disconnected steps

Search results, rankings, full text, citations, notes, and exports live in separate tools.

Response

One evidence-centered workspace

Discover papers, understand every ranking signal, ask PDFs, inspect sources, and retain the result.

Designed for

Students and researchers

Especially useful during topic orientation, rapid evidence mapping, and early literature review work.

02 · Product capabilities

From a broad question
to inspectable evidence.

Each capability is useful alone. Together they form an end-to-end research assistant that still works offline.

⌁

Discovery

Live search with graceful fallbacks

arXiv first, Semantic Scholar second, then local cache and embedded papers when the network cannot help.

arXiv→Semantic Scholar→Cache→Offline
◎

Ranking

Transparent relevance

Title, abstract, topic, and recency signals make every score explainable.

▤

PDF-RAG

Page-aware retrieval

Top-K chunks, section filters, and neighbor expansion preserve context.

◫

Large PDFs

Selective indexing

Process a whole document or a page range, with a warning above 100 pages.

◌

OCR

Optional scan support

Use local Tesseract or an external Unlimited-OCR endpoint without blocking text PDFs.

↗

Output

Memory and export

Keep local sessions and export grounded work as Markdown, CSV, or Excel.

03 · Two connected workflows

Discover the paper.
Then question the full text.

The combined Streamlit application exposes both paths without forcing an API key or external AI service.

01 Paper discovery

  1. AskEnter a natural-language research question.
  2. RetrieveSearch live APIs with cache and offline fallbacks.
  3. NormalizeClean fields and remove duplicates.
  4. RankScore transparent relevance signals.
  5. SummarizeUse local heuristics or optional SAIA.
+

02 PDF knowledge base

  1. UploadKeep private PDFs in a local ignored folder.
  2. ExtractRead selected pages; invoke OCR only when needed.
  3. IndexChunk, embed, and store with metadata.
  4. RetrieveFilter Top-K chunks and add adjacent context.
  5. AnswerCite PDF, page, chunk, section, and excerpt.

06 · Honest boundaries

Grounded does not mean infallible.

  • 01 Rule-based ranking can miss unexpected vocabulary.
  • 02 Answers only see retrieved chunks, not guaranteed complete context.
  • 03 OCR quality depends on document quality and an external backend.
  • 04 The agent supports exploration—not final scientific judgment.
