# Sprint 1

Sprint 1 established the first offline MVP of the Research Paper Discovery Agent.

## Goal

Create a stable and reproducible research workflow that can be demonstrated
without depending on live APIs.

## Implemented Scope

- Research-question input
- Saved demo-paper metadata
- Rule-based ranking
- Abstract-based short summaries
- ChromaDB memory with JSON fallback
- Markdown literature-review export

## Demo Value

The Sprint 1 MVP shows the core workflow from topic input to ranked paper list
and export. It is intentionally offline-friendly to avoid API limits during a
presentation.
